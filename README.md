# jyik347-cloud.github.io

Страница входа VK ID для бота «YouTube → VK Видео» (репозиторий `ggvp`, папка `youtube-to-vk`).

* `vk.html` — открывает вход VK с домена `jyik347-cloud.github.io` (базовый домен приложения VK ID),
  а после «Разрешить» показывает адрес с кодом и кнопку «Скопировать».
* `404.html` — та же страница на случай, если адрес откроется с другим путём.

Здесь нет токенов и ключей: код из адреса бесполезен без секрета `BOT_KEY`, который есть только у бота.
